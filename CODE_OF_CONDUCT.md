# Code of Conduct

We follow the Contributor Covenant (v2.1) in spirit: be kind, be direct,
assume good intent, no harassment of any kind.

- Treat every contributor with respect regardless of background or skill.
- Give actionable, technical feedback. Criticize code, not people.
- Unacceptable: harassment, insults, doxxing, sexual content, sustained disruption.

Enforcement: report to the maintainers via a GitHub issue or the contact
listed in `SECURITY.md`. Maintainers may warn, temporarily ban, or
permanently remove repeat offenders.
